# Leftover Alchemist

A free student prototype for ingredient-based meal ideas, pantry reminders, and feedback.

The app uses built-in recipe templates and browser-local English receipt OCR. Food photos require manual review. Data stays in each visitor's browser; no participant data is included in this repository.

Vendored OCR: Tesseract.js 6.0.1 (Apache 2.0), tesseract.js-core 6.0.0, and English traineddata. See vendor license files.
